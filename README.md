# \# Smart Clean Energy Management System

# 

# This project is part of the Distributed Systems module.

#

# 

# The system uses:

# \- Node.js

# \- gRPC

# \- Protocol Buffers

# 

# Services:

# \- SolarService

# \- BatteryService

# \- EnergyService

# \- RegistryService
